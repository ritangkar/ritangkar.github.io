Match Intelligence

Turns raw match rows into team form and plain-English insights.

DeterministicEngineering experimentsAnalyticsInsightsSpring Boot
View code on GitHub ↗All projects
INTERACTIVE DEMOhard-coded · synthetic data · runs in your browser

The problem

Raw fixtures are hard to read. Analysts want form, trends and a sentence that says what changed.

How it works

  1. Take the last N matches for a team and compute results, points, goal difference, possession and shot accuracy.
  2. Compare home and away scoring.
  3. Fire rule-based insight sentences such as “unbeaten in last 5”.

Technically interesting

The narrative layer is plain rules over statistics, so each sentence can be traced to the rule that produced it.

Why it matters

The data-to-narrative pattern is the same one used for commerce reporting.

Scope & honesty. Synthetic data (8 teams, 56 matches). The demo implements team form only.
