The problem

“We optimised it” is not evidence. Performance claims need a baseline, a change and a measurement.

How it works

  1. Benchmark a full table scan against an index on 100,000 rows.
  2. Measure repeated product lookups with and without a cache.
  3. Compare a 50,000-product list endpoint unpaginated versus paginated, and sequential versus parallel processing.

Technically interesting

The numbers are real and the weakest one is reported honestly: parallel processing gave only 1.29× because the test ran on a single CPU core.

Why it matters

The same measure-first discipline drives the data-model, indexing and query work in my enterprise commerce projects.

Scope & honesty. Measured on a small, single-core test environment. Ratios illustrate the mechanism; they are not production benchmarks.
