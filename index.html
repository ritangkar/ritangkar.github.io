Client Deployed

Enterprise AI Commerce Assistant

An end-to-end enterprise AI chatbot that grounds its answers in SAP Commerce and Service Cloud data, built across a full frontend-to-integration stack.

AngularJavaRAGMulti-Agent OrchestrationSAP Commerce APIsSAP Service Cloud APIs

Overview

An end-to-end enterprise AI chatbot spanning an Angular frontend, Java backend, AI/API integration, multi-agent orchestration, RAG-based knowledge grounding and SAP Commerce/Service Cloud APIs — deployed for one client and currently being adapted for another.

Business problem

Enterprise buyers and support teams often need fast, accurate answers that span product data, order and account context, and service history — information that typically lives across separate SAP Commerce and Service Cloud systems rather than one place.

My role

Led design and build of the assistant end-to-end — the frontend experience, backend orchestration, AI integration, and the SAP Commerce and Service Cloud connections it depends on.

Architecture

Enlarge

How it works

  1. A query is submitted through the Angular frontend.
  2. The Java backend routes it to the agent orchestrator.
  3. Agents retrieve grounding context from enterprise knowledge and from SAP Commerce and Service Cloud data.
  4. A response is composed with that context intact and returned to the user.

Guardrails & quality

The broader AI initiative work applies guardrails, human-in-the-loop review and responsible-AI practices to manage output quality in customer-facing scenarios — the same principles listed under AI & Leadership in the skills section of this site.

Enterprise integration

  • SAP Commerce: product, order and account context is pulled directly from Commerce APIs.
  • SAP Service Cloud: service and case context is connected so answers can span commerce and support.

Status & rollout

Deployed for one client and currently being adapted for a second engagement. Adapting a single assistant to a new client environment is proving to be as much an integration and configuration exercise as an AI one — grounding data and Commerce/Service Cloud connections need to be reconfigured per tenant.
